# Данные backend (data)

## categories.csv

- **category_id** — UUID категории.
- **name** — название категории.
- **subtitle** — подпись/описание.
- **icon_key** — **ключ иконки категории**: по нему фронт/клиент выбирает иконку для отображения (например `food`, `coffee`, `auto`). Это не путь к файлу, а идентификатор типа категории.
- Остальные колонки: budget_amount, audience_segments, rule_id, status, avg_cb_percent, clients_with_category.

### icon_key (иконка категории)

**icon_key** — это строковый идентификатор иконки категории. По нему на фронте или в мобильном приложении подбирается нужная иконка (например из набора или по имени файла `{icon_key}.svg`).

Примеры значений в данных:

| icon_key  | Назначение        |
|-----------|-------------------|
| `all`     | Все покупки / общее |
| `auto`    | Авто, заправки, автосервисы |
| `beauty`  | Красота, салоны   |
| `coffee`  | Кофе, кофейни     |
| `fashion` | Одежда, обувь     |
| `food`    | Еда, рестораны, фастфуд |
| `games`   | Игры              |
| `gifts`   | Подарки, цветы     |
| `home`    | Дом, ремонт, мебель |
| `retail`  | Ритейл, магазины   |
| `services`| Услуги            |
| `sports`  | Спорт             |
| `tech`    | Электроника, техника |

Для новой категории нужно выбрать один из этих ключей или добавить новый и завести для него иконку в UI.

## cb.csv и ML

В **cb.csv** колонка **loyalty_cashback_category_nm** содержит названия категорий кэшбэка. ML принимает запрос с полем `categories` — списком из **21 основной категории** (те же названия, с обычным пробелом):

Автоуслуги, Аптеки, Ж/д билеты, Животные, Заправки, Искусство, Каршеринг, Книги и канцтовары, Красота, Музыка, Образование, Одежда и обувь, Подарки и творчество, Развлечения, Ремонт и мебель, Рестораны, Спорттовары, Супермаркеты, Такси, Фастфуд, Цветы.

В данных значения должны быть нормализованы: неразрывный пробел (`\u00a0`) заменён на обычный пробел, чтобы совпадать с форматом запроса к ML.
